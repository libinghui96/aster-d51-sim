## 二、分阶段闭环验收实测记录

1. **阶段 1：几何校准与机械机构硬精度升级 (`O1 + O2 + O3`)**
   - `O1` 无头像素标定：`Template 6` `ø53mm` 标定 `11.8415 px/mm`（偏差 `+0.26%`）；侧视整车先导轴中心 `168.59 mm`（理论 `168.0 mm`，残差 `0.59 mm`）；底视轮缘外跨 `47.52 mm`（`45.0 mm` 轨距）；`イラスト 9` 华氏配气回动曲柄偏心销 `7.0 mm`、中立位合并杆先导冲程 `2.901 mm`。
   - `O3-1` 圆弧月牙槽：前死点满幅切换逆转机 `[-100%, +100%]` 时滑阀先导漂移仅 `±0.029 mm`（峰峰值 `0.058 mm`，较直线槽提升 6 倍），`t=0` 闭环残差 `1.39e-14 mm`。
   - `O3-3` 跷跷板均衡梁：前后两组 `<tendon>` 耦合悬挂，单轴 `+1.5 mm` 冲击自动向邻轴均载；`R2m` 弯道整列脱线系数 `Y/Q = 0.78 < 0.80`（`SAFE`）对比 `R3m` 孔位 `Y/Q = 0.83`（`MARGINAL`）。
2. **阶段 2：锅炉干烧热损伤与气液两相极限物理 (`O4 + O3-2`)**
   - `O4-1` 坡道假水位：`+3.5°` 上坡时水面计表观水位升至 `78.0%`（真实静水位 `49.7%`），火室前缘浸没水深同步减浅。
   - `O4-2` 空焚き干烧与冷水闪蒸：低水位干烧紫铜火室顶板升至 `490.1°C` 累积退火损伤；高温补水瞬间触发 `flash_steam_spike`，锅筒表压瞬间跃升 `+0.74 kgf/cm²`（`3.71 -> 4.45 kgf/cm²`）顶开安全阀。
   - `O4-4` 冷缸水锤锁死与恢复：`22°C` 冷缸未开排液阀时积水 `1.33 g` 触发 `Hydrolock` 锁死（`RPM = 2.4`），打开排液阀排净凝结水后立即恢复至 `354.7 RPM`。
3. **阶段 3：RTX 5080 GPU 3D 烟室 CFD 标定与自动司炉寻优 (`O5 + O6`)**
   - `O5` 烟室 3D CFD：本机 `NVIDIA GeForce RTX 5080` `7.21s` 并行求解 `165` 组 `[40×40×56]` 三维流场，烟室负压覆盖 `6.5 ~ 147.7 Pa`，引风倍率 `0.231 ~ 1.257`，热效率 `8.1% ~ 43.4%`。
   - `O6` 自动司炉寻优：`47.35s` 并行评估 `114,688` 条轨迹，导出 `P_target = 3.86 kgf/cm²`、巡航省汽截止比 `55.9%`；在 `d51_r2m.xml` 整列 3D 闭环测试中自动开阀暖缸、随速收短截止比且安全阀白白泄压占比 `0.0%`。
4. **阶段 4：Web 3D WASM 数字孪生终极版同步 (`M4+`)**
   - `web/public/models/manifest.json` 完整挂载 `2` 个 MJCF、`20` 个 STL 及 `3` 个 JSON 配置（`d51_mass_props.json`、`smokebox_lut.json`、`auto_fireman_policy.json`），`tsc && vite build` 零告警通过，并在 `mujoco_wasm` 下完成 R2m 自动司炉巡航与水锤锁死/恢复闭环验证。
5. **阶段 5：配气力臂与相位校准 + 36 件精密走行/华氏全金属连杆升级 (`P0-A / V2-GEAR`)**
   - **逆转力臂与中立锁死截汽修复**：恢复 `4-12` 逆转横轴 `11.0 mm` 真实水平力臂并按双圆求交等长闭合左右 `2-10` 吊杆（`11.000 mm`，机器精度残差 `1.73e-15 mm`），`±25.8°` 物理转角驱动月牙滑块满行程 `±4.15 mm`、滑阀冲程倍增至 `5.63 mm`；外余面校准至 `0.78 * lead_amp (1.17 mm)` 后，热态 `3.8 kgf/cm²` 中立档 `N` 锁死不转，冷态 `1.0 kgf/cm²` 正反转顺畅自起动（`+453.7 / -459.1 RPM`），正转四拍排气间隔精准至 `89.89°—89.89°—89.88°—90.34°`（最大偏差仅 `0.34°`）。
   - **36 件水密 CAD 网格、耦合连杆分段铰接与月牙板下尾耳修正**：补建第 3 主动轮（加长三阶曲柄销 + 大扇形配重）、`7-10` 回动曲柄、`2-5` 配气导轨托架、华氏 5 根不锈钢细杆（彻底淘汰胶囊近似杆）、`6-3` 给水泵黄铜偏心环、`19-2` 先导台车架（含 `20-6` R2m/R3m 双孔槽）与 `19-11` 从轮台车架；修正 `2-4` 月牙板下尾颈高度符号计算（消除偏心杆耳孔下方多余的 `-24.3 mm` 方柄凸出，圆弧尾耳精确终止于 `-15.7 mm`）；四轴耦合连杆升级为三段铰接节（Knuckle Pin），单轴 `+1.5 mm` 颠簸自由折角 `-1.977°`，R2m 弯道峰值脱线系数优化至 `Y/Q = 0.73 < 0.80`（`SAFE`）。
6. **阶段 6：炉内热流管网与泵阀无头提取 + 40 件紫铜内胆/过热器/燃烧器/泵阀 CAD 建模 (`P0-B / V2-BOILER-CAD`)**
   - **1:1 模板像素核验与全套管网/泵阀真值表**：新增 `scripts/08_extract_boiler_valves_bom.py` 自动测量 `Template 6`（`ø53.0 mm` 锅筒内径）、`Template 5`（烟室 `ø64.86 × 70.43 mm`）与 `Template 2`（火室 `64.86 × 48.98 mm`），计算受压内胆几何净容积 `401.8 ml`（扣除撑杆管件后对齐标称 `380 ml`）、总蒸发受热面积 `181.05 cm²`、4 折过热器受热长 `520.0 mm`（`52.28 cm²`）、`20-7` 乏汽喷嘴 `ø4.2 mm`（`13.854 mm²`）及全套泵阀特性参数，输出 `configs/d51_boiler_piping.json`。
   - **4 组锅炉内脏水密 CAD 与全透视 X-Ray 内窥**：新增 `boiler_firebox_flues.stl`（`C1100` 紫铜内火室+平顶板撑螺母+双火管，`426.66 g`）、`superheater_piping.stl`（`SUS304` 汽包立管+4 折返弯过热管+分叉主蒸汽管+`20-7` 喷嘴+`18-25` 烟囱裙罩，`90.53 g`）、`alcohol_burner.stl`（三头毛细灯芯杯+恒液位供油管，`29.92 g`）与 `boiler_aux_valves.stl`（`6-5` 黄铜轴动泵阀体+逆止阀+置换注油器+驾驶室 `11-7` 水面计/压力表/旁通阀，`41.03 g`），全车扩展至 **40 件水密 STL**，注入 `loco_frame` 复合惯量（**零新增自由度**，`njnt=53`），并在 `web/` 打通紫铜/不锈钢/黄铜分材质渲染与「锅炉内胆+气缸全透视 X-Ray 内窥」。
